# corpus/

Teaching material for the corpus-extension experiment. The notebook's loader reads
every `.txt`, `.md` and `.pdf` here (subfolders included) and ignores this README.

All files in this folder are written for this assignment and may be shared freely.
They contain no eval prompts, answer keys, or eval outputs; `check_corpus.py` in the
repository root verifies that before each training run.

Experiment 1 (starter corpus) ran with this folder empty. Experiment 2 (expanded
corpus) ran with the files listed in the top-level README.
